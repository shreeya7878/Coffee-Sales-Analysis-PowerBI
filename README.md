# ☕ Coffee Sales Analysis Dashboard

An interactive coffee sales analysis dashboard built using Microsoft Power BI to identify sales trends, top-performing coffee types, and revenue patterns.

## 📊 Dashboard Overview

The dashboard provides an interactive view of:

- Total Revenue
- Total Transactions
- Average Transaction Value
- Revenue by Coffee Type
- Monthly Revenue Trend
- Revenue by Time of Day
- Revenue by Weekday

## 🔍 Key Insights

- Latte generates the highest revenue among coffee types.
- March records the highest monthly revenue, followed by October.
- Night and Afternoon generate the highest revenue by time of day.
- Tuesday records the highest weekday revenue.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Data Analysis
- DAX

## 📁 Project Files

- `Coffee_Sales_Analysis.pbix` – Power BI dashboard file
- `Dataset` – Source dataset used for analysis

## 🎯 Objective

The objective of this project is to analyze coffee sales data and transform it into an interactive business dashboard that helps identify revenue trends and customer purchasing patterns.
